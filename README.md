# Tap Points - Android AdMob Test App

This is a simple Android app project for testing the full app + advertising workflow.

Features:
- Tap button: +1 point
- Local point saving
- Rewarded test ad: +25 points
- Banner test ad
- Google Mobile Ads SDK

IMPORTANT:
The project uses Google's official TEST AdMob App ID and TEST ad unit IDs.
Do not use these IDs in a production release.

Next steps:
1. Upload/import this Android project into a cloud Android build environment.
2. Build an APK.
3. Install the APK on an Android phone.
4. Test tapping, saved points, banner ads, and rewarded ads.
5. Create your own AdMob account/app and replace the test IDs before release.
